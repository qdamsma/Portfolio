# Portfolio – Quinten

Persoonlijke portfolio website gebouwd met React en Vite.

## Starten

```bash
npm install
npm start
```

## Beschikbare scripts

```bash
npm start        # Start ontwikkelserver
npm run build    # Productie build
npm run preview  # Bekijk productie build lokaal
npm run lint     # ESLint uitvoeren
```

## Technologieën

- [React 19](https://react.dev/)
- [Vite](https://vite.dev/)
- [React Router](https://reactrouter.com/)
- SCSS
